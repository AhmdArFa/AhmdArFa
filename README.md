## 👨‍💼 نبذة مهنية / Professional Overview

مهندس بيانات وذكاء اصطناعي وأنظمة برمجية متكاملة، يمتلك خبرة عملية رائدة في:
- 🏛️ **الأنظمة الحكومية والوطنية**: المساهمة في تطوير منظومة التدقيق والفحص لمنحة **DEPI (وزارة الاتصالات)** والتي تخدم آلاف المتقدمين مع ميزات الذكاء الاصطناعي (OCR) ومعالجة الوثائق الرسمية والمزامنة اللحظية بين قواعد البيانات وملفات الإكسيل.
- 📊 **ذكاء الأعمال وتحليل البيانات**: تصميم وبناء أكثر من 4 لوحات تحكم تنفيذية (Executive Dashboards) بـ **Power BI** قلصت زمن إعداد التقارير بنسبة 60%، وخطوط أنابيب بيانات (SQL ETL) عالجت آلاف السجلات بدقة فائقة.
- 🤖 **هندسة الذكاء الاصطناعي و Computer Vision**: تطوير نماذج متقدمة لتصنيف الأمراض الزراعية والتعرف على المستندات الرسمية بدقة تخطت 97%، وبناء مساعدين أذكياء يعتمدون على تقنيات **RAG** و **LLMs**.
- ⚙️ **الخوادم وهندسة الـ APIs**: بناء خدمات RESTful آمنة باستخدام **FastAPI** وتأمينها عبر **JWT Authentication** وصلاحيات الأدوار (RBAC).

## 🌟 أبرز المشاريع المنفذة / Featured Projects

### 🏛️ [DEPI Applicant Validation Solution](https://github.com/MCIT-DEPI/DEPI-Validation-Solution)
> **منظومة فحص وتدقيق طلبات ومستندات متقدمي رواد مصر الرقمية (MCIT - DEPI)**
- خادم **FastAPI** متكامل مع **MongoDB** و **React 19** لمعالجة وتدقيق مستندات الآلاف من المتقدمين.
- محرك مزامنة لحظية ثنائية (**MongoDB & Excel Dual-Sync**) للتزامن مع سجلات المشرفين مع نظام مقاومة أقفال ملفات ويندوز.
- بنية تحتية ذاتية التعافي (**Self-Healing Master Admin**) لضمان استمرارية الإدارة العليا للنظام.
- كانفاس فحص تفاعلي ذكي يتيح تكبير وتدوير مستندات الرقم القومي والشهادات وفحصها بدقة.

### 🍊 **NILEX.AI — Smart Green Ecosystem for Egyptian Agricultural Exports**
> **منصة ذكاء اصطناعي لدعم اتخاذ القرار وتصنيف جودة صادرات الحاصلات الزراعية**
- دمج نموذج **YOLOv8n** لاكتشاف الثمار (`mAP@0.50:0.95 = 0.81`) ومصنف **ResNet-50** لأمراض الموالح (`Macro-F1 = 0.978`) بزمن استجابة أقل من 3 ثوانٍ.
- معمارية Microservices مستضافة على **Microsoft Azure** مع **PostgreSQL** و **FastAPI** ولوحات معلومات **Power BI**.
- دعم المساعد المعرفي الزراعي بتقنيات **RAG** وواجهة صوتية عربية (Arabic Speech-to-Text).

### 🏥 **Hospital Patient Flow Command Center**
> **مركز قيادة ومتابعة تدفق المرضى والإيرادات التنفيذية بالمستشفيات**
- لوحة تحكم تفاعلية عبر **Power BI** و **SQL** تتابع 300 مريض عبر 8 أقسام طبية وإيرادات بلغت 37.44 مليون جنيه مصري.
- قلصت وقت المراجعة والتدقيق الإداري بنسبة 50%.

### ⚡ **SQL Data Quality & Machine Learning Pipelines**
- تصميم خطوط أنابيب تنقية ومطابقة بيانات SQL فحصت أكثر من 4,000 سجل مع آليات كشف الازدواجية والتكامل الدلالي.
